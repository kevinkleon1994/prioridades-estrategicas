## Arquivos para enviar ao GitHub

Envie para a raiz do repositório:

- `index.html`
- `styles.css`
- `app.js`
- `config.js`
- pasta `assets`

O diretório `google-apps-script` é apenas para guardar uma cópia do backend e não precisa ser publicado pelo GitHub Pages.

## Responsividade

- Desktop e projetor: navegação lateral, quatro cartões e painéis lado a lado.
- Tablet: cartões em duas colunas e detalhes empilhados.
- Celular: menu lateral recolhível, formulários em uma coluna e controles próprios para toque.

## Publicar no GitHub Pages

1. Substitua os arquivos atuais pelos arquivos da V4.
2. Faça o commit.
3. Abra `Settings > Pages`.
4. Escolha `Deploy from a branch`.
5. Branch `main`, pasta `/root`.
6. Acesse:
   `https://kevinkleon1994.github.io/prioridades-estrategicas/`

## Importante

O Apps Script precisa estar com o `Code.gs` da versão corrigida, incluindo suporte a JSONP, e implantado como uma nova versão do Aplicativo da Web.
